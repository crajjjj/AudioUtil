# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Mod Is

**AudioUtil** is an SKSE64 plugin (C++ DLL, built on CommonLibSSE-NG for Skyrim SE 1.6.1170, all-runtime) plus a small Papyrus API layer. It provides **native, folder-path-based WAV playback** — playing loose audio files directly with **no SNDR/SOUN sound-descriptor forms and no ESP edits**.

Core mechanism: `RE::BSAudioManager::BuildSoundDataFromFile` + `BSResource::ID::GenerateFromPath` play loose files; a `BSSoundHandle` gives per-instance volume / stop / 3D actor-follow. Voice audio is organized on disk as `<slot path>\<Category>\*.wav`, where the slot path is the `[[slot]]` `path` (a full `Sound\...` Data-relative folder); slots are named like `F1`, `M1`..`M8`, `C1`.. A `PlayVoice(actor, "Category")` call resolves the actor's slot (npc_overrides → voicetype_remap → voicetype_map → race_map → per-sex default), then **shuffle-bag** picks a wav from the category folder (no repeats until the deck empties).

Beyond raw playback it also provides:
- **Lipsync** — reads the wav's amplitude envelope (100 Hz RMS) and drives the actor's MFG `Aah`/`BigAah` phonemes per game frame. No `.lip` baking, no dialogue records; works for any loose PCM wav.
- **Captions** — a wav with a same-named `.toml` sidecar (`moan_03.wav` + `moan_03.toml`, keys per language: `en = "..."`, `ru = "..."`) shows its text as a real game subtitle attributed to the speaker while the line plays, plus an `AudioUtil_Caption` mod event. See `CaptionManager`.
- **PPA bridge** — optional integration with the third-party Accurate Penetration plugin (`AccuratePenetration.dll`), republishing penetration depth/context to Papyrus as throttled mod events. See [PPA Bridge](#ppa-bridge-accurate-penetration).
- **TomlUtil** — a generic, audio-independent TOML-file reader API hosted by the same DLL, usable by any consumer mod.

The plugin itself is **game-neutral and ships SFW by default** (the default `AudioUtil.toml` defines no slots or SFX). Game-specific presets (voice-slot / category / SFX mappings) are shipped by **consumer mods** (e.g. *Hentairim p+*, *SLO VE*) via a TOML that overwrites the neutral default through load order.

## Build

Two independent build steps, both driven by **xmake** (`xmake.lua`).

### C++ DLL (xmake + CommonLibSSE-NG)

```
xmake f -m release        # configure release (VS2022 v143, C++23)
xmake                     # build DLL -> dist\SKSE\Plugins\AudioUtil.dll
```

- Requires **VS 2022 (v143, C++23)** and **xmake ≥ 3.0** (the lib's xmake.lua demands it).
- **CommonLibSSE-NG is a git submodule** at `lib/commonlibsse-ng` — the maintained **alandtse/CommonLibSSE-NG** fork (v7.0.0+, supports the latest Skyrim runtimes). Before the first build you MUST run `git clone --recurse-submodules` or `git submodule update --init --recursive` (this also pulls its nested `extern/openvr` submodule) — it is not vendored. v7 renamed `BuildSoundDataFromFile`→`GetSoundHandleByFile` and the facegen keyframe blocks (`unk120`→`phoneme1` etc.), and its headers pull real `Windows.h` (hence `NOMINMAX` + `#undef GetObject` in PCH.h/xmake.lua).
- `toml++` (v3.4.0) comes via xmake `add_requires`; the version is pinned in `xmake-requires.lock` (`package.requires_lock` enabled).
- Sources: `add_files("src/**.cpp")`; includes `src` and `include`; PCH is `src/PCH.h`.
- Exports are controlled by `exports.def` (`SKSEPlugin_Load` + the `AudioUtil_*` C API, see `AudioUtilAPI`), applied via `add_shflags("/DEF:...")` — shared targets link with shflags; `add_ldflags` is silently ignored for them.
- `after_build` copies the DLL (and PDB in debug) into `dist\SKSE\Plugins\`. With `xmake f --copy_to_mod=y` and env `XSE_TES5_MODS_PATH` set (e.g. `E:\nefaram\mods`), it also copies `dist\*` into `<mods>\AudioUtil` for live testing.
- Debug: `MTd`, `DEBUG`, `/bigobj`. Release: `MT`, `NDEBUG`, `/O fastest`, debug symbols.

### Papyrus scripts + release packaging (Pyro)

```
xmake build papyrus       # Pyro: papyrus\Source\*.psc -> dist\Scripts + Release\AudioUtil-<version>.zip
xmake build release       # rebuilds the DLL first (add_deps AudioUtil), then runs Pyro
xmake build lipsim        # zip tools\lipsim -> Release\AudioUtil-LipSim-<version>.zip (standalone authoring tool)
```

- `scripts/pyro.lua` mirrors `papyrus\Source\*.psc` into `dist\Scripts\Source`, then runs `pyro.exe -i AudioUtil.ppj --game-path <game>`. Afterward it renames the ppj's `Release\AudioUtil.zip` to **`Release\AudioUtil-<version>.zip`** — the version is passed in from `xmake.lua` `PROJECT_VERSION` (single source of truth; the static `.ppj` can't template it).
- `pyro.exe` is auto-located from the VSCode papyrus-lang extension (`%USERPROFILE%\.vscode\extensions\joelday.papyrus-lang-vscode-*\pyro\pyro.exe`). Override with env **`PYRO_EXE`**.
- Game root defaults to `C:\SteamLibrary\steamapps\common\Skyrim Special Edition`; override with env **`SKYRIM_GAME_PATH`**.
- **VSCode default build task** (`Ctrl+Shift+B`, `.vscode/tasks.json`) runs the same `AudioUtil.ppj` via the `pyro` task type, with `gamePath` hardcoded to the same Steam path.

`AudioUtil.ppj` has `Zip="true"`, so **every Pyro run refreshes the release archive** — a ready-to-install mod archive (`<ZipFiles>` RootDir `.\dist`, matching `Scripts\*.pex`, `Scripts\Source\*.psc`, `SKSE\*.*`), which `pyro.lua` then renames to **`Release\AudioUtil-<version>.zip`** (version from `xmake.lua` `PROJECT_VERSION`). This is the BFNG convention where Pyro owns release packaging.

## C++ Source Architecture (`src/`)

`main` wires SKSE messaging; on `kDataLoaded` it runs `Config::Load` → `FolderCache::Rebuild` → `GagState::Resolve` → `TongueState::Resolve` → `InstanceManager::ApplyConfigGroupVolumes` → `LipSync::ApplyConfig` → `CaptionManager::ApplyConfig` → `FuzSlots::Configure` → `FuzCache::EnforceCacheCap` → `PPABridge::TryConnect` → `PrewarmFuzCache` (background). A `PlayVoice` call flows: `PapyrusAPI::ResolveSlotForActor` (uses `Config` maps) → `ResolveGaggedKey` (gag redirect, see `GagState`) → `FolderCache::ResolveVoiceKey` + `PickNext` → `AudioEngine::PlayPath` (fuz → `FuzCache` decode → `FuzSlots` placeholder) → `InstanceManager::Register` (+ optional channel, holds the fuz slot) → `LipSync::Start`.

| File | Role |
|---|---|
| `main.cpp` | SKSE entry point; spdlog init; registers Papyrus funcs; runs the kDataLoaded config/scan pipeline; on kPreLoadGame/kNewGame stops all audio and resets lipsync |
| `AudioEngine` | Thin wrapper over `BuildSoundDataFromFile`; `PlayPath(dataRelPath, follow, volume[, flags, priority])` → `BSSoundHandle`. `follow` (an actor) 3D-positions the sound at that actor; passing `nullptr` plays it flat/2D at full volume. Voice calls pass `follow` only when `[general] voice_3d` is set (default true). A `.fuz` path is transparently swapped for its `FuzCache`-extracted payload at the build step only — callers keep registering/lipsyncing/captioning against the original path |
| `FuzCache` | `.fuz` voice-container support: `Resolve(path)` reads the fuz through the engine's resource loader (`BSResourceNiBinaryStream`, so **BSA-packed fuz work** — any vanilla dialogue line is playable by path), parses the FUZE header (magic/version/lipSize, then LIP block, then RIFF audio) and **decodes the xWMA payload to 16-bit PCM** via the OS WMA decoder DMO (`CLSID_CWMADecMediaObject`, GUIDs spelled out, `ole32` syslink; xWMA omits codec extradata — fabricated as ffmpeg's xwma demuxer does, 10 zero bytes with `wEncodeOptions=0x1F`), caching a plain **`.wav`** at `Data\Sound\AudioUtilFuzCache\<stem>_<fnv1a-hash>.wav`, reused across sessions (delete the folder freely; failures are session-cached). PCM cache = reliable playback + envelope lipsync for fuz (`LipSync::Start` maps a fuz path to its cached wav). Decode failure falls back to caching the raw `.xwm` (plays, no lipsync). `EnforceCacheCap` (kDataLoaded + ReloadConfig) bounds the folder to `[general] fuz_cache_max_mb` (default 256, 0 = unlimited), deleting oldest-written files first and dropping the session resolve map. `ReadLipBlock(path)` extracts the embedded LIP block for `LipData` — fuz lines get **real phoneme lipsync** from their authored curves (slot map engine-verified — slots 0–15 = MFG phonemes, 16–32 = the 17 MFG modifiers BlinkLeft..HeadYaw; calibration methodology in `docs/lip-format-research.md`, whose payload-grammar sections are superseded — the byte format spec is `tools/lipresearch/RLE Hypothesis.md` §11–12 / `LipData.cpp`). **First-play gotcha:** Skyrim indexes loose files only at launch, so a cache wav written mid-session is unreadable by the audio loader until the next restart (worse under MO2/USVFS) — a first-ever fuz play was silent. `FuzSlots` fixes it; `[general] prewarm_fuz` optionally decodes-ahead in the background at load to skip the first-play decode hitch |
| `FuzSlots` | In-session fuz playback (the fix for the first-play gotcha above). Ships a pool of pre-indexed placeholder wavs `Data\Sound\AudioUtilFuzCache\_au_slotNN.wav` (created by `Configure(N)` at load if missing; N = `[general] fuz_slots`, default 24, 0 = disabled). The engine **re-reads a file's bytes on every `BuildSoundDataFromFile`** (verified by the `autest boverwrite`/`bbase`/`bswap` probe), so `AudioEngine::PlayPath` routes a fuz-derived cache wav through a free slot: `AcquireWithCopy` copies the decoded PCM into the slot file (plain IO, so USVFS surfaces a mid-session write the resource loader can't) and builds from the slot's already-indexed path → audible first try, no restart. The slot is held until the instance stops (`InstanceManager` releases it on every stop path + `SweepNow()` before each play), so it's safe whether the engine loads-at-build or streams. N = max simultaneous fuz lines. Only `.wav` cache paths route (an `.xwm` decode-failure fallback keeps its ext); a slot build failure falls back to the direct cache path; slot files are excluded from `EnforceCacheCap` eviction |
| `Config` | Merges the base `Data\SKSE\Plugins\AudioUtil\AudioUtil.toml` then every `AudioUtil\config\*.toml` overlay (sorted filename order) into one `Settings` struct (slots, resolution maps, category aliases/fallbacks, sfx table, group volumes, flags/priority, ppa + lipsync + gag). `MergeFile(settings, root, isBase)` accumulates **additive** collections (slots/maps/sfx/`[gag].keywords`/`[gag].items`/`[lipsync].block_categories` union, last-writer-wins per key) from every file, but **global scalar** sections (`[general]`, `[ppa]`, the `[lipsync]` scalar tuning, and `[gag]` enable/default_category) are honored **only from the base** — an overlay that sets them is ignored with a warning. (`[gag].keywords`, `[gag].items` and `[lipsync].block_categories` are the additive exceptions carved out of their otherwise base-only tables.) `[[slot]]` is keyed by `id` (whole-slot last-wins, no deep merge); `race_map` is sorted longest-hint-first once after all files merge. Slot `sex` is `'F'`/`'M'`/`'A'` — `'A'` (all/neutral: creatures, sfx) matches either sex on explicit routes but is skipped by the blind default-by-sex fallback; for the category layer it shares the male aliases/fallbacks (where creature/neutral fallbacks are authored) and skips `male_only_remap`. Each file parses independently — a broken overlay is skipped, and settings are only replaced if ≥1 file parsed. Slot `path` and `[sfx]` values are always full `Sound\...` Data-relative paths (resolved identically). A `[slot.categories]` value may be an **array** (explicit file list, BSA-capable) or a **string** (one folder to scan; `Sound\...` = full Data path, else relative to the slot's path); a slot may name a `fallback` slot consulted per-category when it resolves nothing (chain capped at 4 hops), and a `gag_slot` used when the actor is gagged. A slot may set `script_only = true` to mark it as reached only by `PlayVoiceFromSlot` (never actor routing), which suppresses the wiring audit's "has audio but no route" orphan warning for it. `[gag]` parses `enable`, `default_category`, and two additive `Plugin.esp|FormID` marker lists — `keywords` (worn-keyword match, whole device family) and `items` (specific worn item forms). `[tongue]` parses `enable` (base-only) + the same additive `keywords`/`items` lists (both share the file-scope `ParseFormRefs` helper). `Normalize` (lowercase + strip non-alphanumerics), `MakeNpcKey`, `FindSlot`. Keeps prior settings on parse error |
| `GagState` | Resolves `[gag]` markers via `TESDataHandler` (on load + reload) — `keywords` → `BGSKeyword*`, `items` → `TESBoundObject*`; `IsGagged(actor)` walks the actor's worn items, matching either a listed item form directly or any item carrying a gag keyword. Dormant when nothing resolves. Used by `PapyrusAPI::ResolveGaggedKey` to route a gagged speaker's voice through the slot's `gag_slot` (with `default_category` as the muffled catch-all) |
| `TongueState` | Parallel of `GagState` for `[tongue]` markers (resolved on load + reload, same `keywords`→`BGSKeyword*` / `items`→`TESBoundObject*` scheme). `IsWearingTongue(actor)` walks worn items the same way. **Detection only — no voice rerouting**; consumed solely by `LipSync` to suppress lipsync while a tongue armor is worn (a visible tongue needs the mouth held open; the jaw-flap would clip it). Dormant when nothing resolves |
| `FolderCache` | Scans slot roots + per-category folder refs + sfx folders, registers explicit file lists (which win over same-named scanned folders); resolves slot+category (aliases / male_only_remap / category fallbacks, then the slot's `fallback` slot chain) to a folder; shuffle-bag `PickNext` + `FileCount`. **Scans see loose files only — BSA audio needs explicit file lists** |
| `InstanceManager` | Owns live sound instances behind `int32` ids; per-instance IsPlaying/Stop/Duration/volume; group volume/duck/stop; channel exclusivity (`PlayOnChannel` stops previous occupant); StopAll |
| `LipData` | Parser for the Skyrim `.lip` format, **engine-verified by decompiling the game's FUZE/lip loader** (SkyrimSE.exe 1.6.1170): a 24-byte header (or 20-byte prerollless, `const14=7`; variant B's extra byte at 14 normalized) then a **zero-RLE-compressed** payload (`0x00` + u16-LE count = that many zero bytes, other bytes literal) decompressing to a **dense `float32[frames*33]` grid**, frame-major, every value a signed channel weight in [-1,1] (slots 0-15 phonemes, 16-32 the **17** modifiers BlinkLeft..HeadYaw — no padding slot; head channels 30-32 are routinely negative; trailing rest run omitted -> zero-filled to `frames*33`). The u16 right before the payload is a **start token**: `token>>2` leading zero cells are prepended before decompressing — skip it and every channel decodes rotated (the pre-0.9.16 bug; correction credit Raynor1511, `RLE Hypothesis.md` §12). `Parse` decompresses then reads the grid into dense per-channel timelines, played verbatim (no added fades — authored curves already ramp; corrupt cells are skipped, and a mostly-corrupt decode falls back to the envelope). The long-assumed dup/tangent/marker "grammar" was a misreading of the compressed bytes and is gone (`tools/lipresearch/RLE Hypothesis.md` section 11). `GetFor(path)` resolves a played path's lip (same-stem `.lip` — loose or BSA — or a `.fuz`'s embedded block) with session caching (misses too); empty lips return null so callers fall back to the envelope. No game deps beyond the resource reader |
| `LipSync` | Drives the actor's mouth in sync with a playing instance, two modes per line: **lip mode** (when `LipData::GetFor` finds authored curves and `[lipsync] use_lip_files` is on — **default on** since the `.lip` format is engine-verified — writes all 16 MFG phoneme channels from the `.lip` timeline verbatim, with a master fade for starts/stops; optionally the 17 modifier channels too via `drive_modifiers`, default **on**; `lip_jaw_boost` (default 0.5) lifts `Aah` to that fraction of the frame's strongest channel so authored speech — which holds the jaw low ~80% of voiced time — still reads as an open mouth at camera distance, skipped while `BMP` presses the lips and never on pseudo lips) falling back to the **amplitude envelope** (100 Hz RMS → `Aah`/`BigAah`, attack/release/gain/min-level). With `[lipsync] pseudo_phonemes` (default off), envelope-only lines instead get **synthesized pseudo-phoneme curves**: the envelope is split into syllables (voiced runs, split at deep valleys), each syllable opens one phoneme from a corpus-weighted 16-channel palette (seeded by file path — deterministic per wav; `[lipsync] pseudo_speechiness` lerps the pick from open-mouth moan vowels at 0 to the full speech distribution incl. consonants at 1, weights measured from 638 real vanilla lips), with `BMP` lip closures placed after ≥165 ms silence gaps; the result is a `LipData::Anim` played through the normal lip-mode path (envelope shaping baked in at synthesis). Both lip and pseudo playback sample the 30 fps grid through `[lipsync] frame_interpolation` (`LipData::g_frameInterp`, default 0.3): 0 holds each frame's value (raw stepped playback), 1 is a full lerp to the next frame, between travels that fraction of the delta inside the frame and steps the rest at the boundary — whether the engine itself lerps or steps is unverified, so this is the A/B knob (live on `au reload`). Runtime A/B toggles: `autest lipfiles on\|off`, `autest pseudolip on\|off` (affect new lines). Skips non-PCM/BSA-packed audio and creatures without facegen. Suppressed for gagged actors via `GagState::IsGagged`, for actors wearing a tongue armor via `TongueState::IsWearingTongue`, and for actors in a dialogue with the player via `RE::MenuTopicManager::speaker` (`[lipsync] block_in_dialogue`, default true — the game drives that mouth): all checked at `Start` and re-checked on a 500 ms throttle (`handoverCheckAt`/`HANDOVER_RECHECK`) so a gag/tongue equipped or a dialogue started mid-line hands the mouth over. Also skipped per-call (`blockLipSync`) and per-category (`[lipsync] block_categories`, matched on the requested category name in `PlayVoice`/`PlayVoiceFromSlot` — for oral-sfx / climax pools that shouldn't move the mouth) |
| `CaptionManager` | On-screen captions: `Start(speaker, path, handle, id)` reads the wav's same-named `.toml` sidecar (per-language keys; cached, misses cached silently — missing sidecars are the common case), resolves the `[captions]` language (`auto` = game's `sLanguage` ini mapped to two-letter codes, fallback `en`), sends the `AudioUtil_Caption` mod event (strArg=text, numArg=instance id, sender=speaker) and — when `hud` is on — injects an `RE::SubtitleInfo` (`forceDisplay`, targetDistance = real player→speaker distance so overlapping captions resolve closest-speaker-first, PC = 0) into `RE::SubtitleManager` under its spin lock on the game thread, so the HUD renders it like a real overheard-dialogue subtitle (speaker name included). A 250 ms ticker (same leaked-detached-thread pattern as `LipSync`) sweeps entries when the instance stops playing and erases the injected `SubtitleInfo` (matched by speaker handle + exact text). Wired into `PlayFromKey` (speaker passed separately from the lipsync mouth actor, so `blockLipSync`/`voice_3d=false` lines still caption) and `PlayFile`; loose-file sidecars only |
| `PPABridge` | Dynamically connects to `AccuratePenetration.dll`; per-receiver snapshot cache under a mutex; sends throttled `AudioUtilPPA_Update`/`AudioUtilPPA_End` mod events via the SKSE task interface |
| `PapyrusAPI` | Registers all natives across `AudioUtil`, `AudioUtilPPA`, `TomlUtil`; holds actor→slot resolution (`ResolveSlotForActor`, `PickFromSlotList` with per-NPC spreading via `StableLocalID`) — where a **creature** (`IsCreature`: race carries no `ActorTypeNPC`, via `IsHumanoid()`) that no explicit route claimed takes `[general] default_creature_slot` and **stops**, never the by-sex default, whose blind scan only reaches `'F'`/`'M'` human packs (an unmapped frostbite spider otherwise spoke a male voicepack; unset = silent, so `GetSlotForActor` returns `""` and a script can test first) — the `ResolveGaggedKey` gag-routing helper, the shared `PlayFromKey` helper, and `PlayFileByPath` (shared body of the PlayFile natives, also the backend of `AudioUtilAPI`) |
| `AudioUtilAPI` | Native C++ inter-plugin API (SLA-NG-style): `extern "C"` exports `AudioUtil_GetVersion` / `AudioUtil_GetInterfaceVersion` / `AudioUtil_PlayFile` / `AudioUtil_PlayFileWithLipSync`, thin null-safe forwarders onto `PapyrusAPI::PlayFileByPath` (identical semantics to the Papyrus natives, handles share the same id space). Exported via `exports.def`; consumers resolve at runtime with `GetModuleHandleA("AudioUtil.dll")` + `GetProcAddress` against the reference header `include/API/AudioUtilAPI.h` (no link-time dependency). Interface version is append-only, packed MMmmpp |
| `TomlStore` | Generic lazily-parsed/cached TOML reader/writer backing `TomlUtil`; caches parse failure (one warning); missing file/key/type-mismatch returns caller's default; rejects absolute paths and `..` traversal. `Set*` writers splice the value into the file **text** in place via `TomlEdit.h` (comments/formatting survive; new keys insert under the table header, new tables/files are created), round-trip-validate before writing, and refresh the cache; unsafe/unsupported edits return false with nothing written |
| `TomlEdit.h` | Pure comment-preserving TOML text-splice algorithm used by `TomlStore` setters (toml++ source-region replace + header-anchored insert + re-parse validation). No game deps — unit-testable standalone |
| `PCH.h` | Precompiled header |

## Papyrus API Surface (`papyrus/Source/*.psc`)

Every `Play*` returns an `int` instance handle: `>0` success, `0` = nothing played. Effective volume = `volume × group_volume × duck_factor`. A **channel** is an exclusivity lane (playing on an occupied channel stops the previous instance).

**`AudioUtil.psc`** (`Hidden`) — core API. Natives:
- Play: `PlayVoice(Actor, category, volume, group, channel, blockLipSync=false)`, `PlayVoiceFromSlot(slot, category, akFollow, volume, group, channel, blockLipSync=false)`, `PlaySFX(sfxName, Actor, volume, group="sfx", channel)` (resolves `sfxName` first as a category of the **sfx slot** — `[general] sfx_slot`, default `SFX0` — then the flat `[sfx]` table, via `PapyrusAPI::ResolveSfxKey`; the sfx slot gives sfx pools the full `[[slot]]` toolset incl. BSA file-lists), `PlayFile(dataRelPath, Actor, volume, group, channel)` (never lipsyncs — unchanged legacy semantics; also serves non-vocal one-shots), `PlayFileWithLipSync(...)` (same args, spoken-line variant: drives the actor's mouth like a voice call), `PlayFolder(dataRelFolder, Actor, volume, group, channel)` (no auto-lipsync), `PlayFolderWithLipSync(...)` (spoken-line variant). `blockLipSync=true` = play this one line without moving the mouth (per-call opt-out; a mod that owns an actor's face across many lines passes `true` on each — there is no standing per-actor block). A category listed in `[lipsync] block_categories` also never lipsyncs.
- Handles: `IsHandlePlaying`, `StopHandle`, `GetHandleDuration`, `SetHandleVolume`, `GetHandlePath` (data-relative path of the file the handle played — the exact shuffle-bag pick; read right after the Play* call).
- Groups/channels: `SetGroupVolume`, `DuckGroup(group, factor=0.0)`, `UnduckGroup`, `StopGroup`, `StopAllAudio`, `StopChannel`.
- Lipsync: `IsLipSyncActive(Actor)`, `StartLipSync(Actor, handle)` (attach lipsync to an already-playing instance — for PlayFolder or re-attach), `StopLipSync(Actor)`, `SetLipSyncEnabled(bool)`, `IsLipSyncEnabled()`, `SetLipSyncGain(float)`. Owning an actor's face is per-call via `blockLipSync` (no standing block native).
- Captions: `GetHandleCaption(handle)` (sidecar text for the current `[captions]` language), `SetCaptionsEnabled(bool)`, `AreCaptionsEnabled()`; mod event `AudioUtil_Caption(text, handleAsFloat, speakerForm)` fires on every captioned line (even with `hud = false`).
- Introspection: `GetSlotForActor(Actor)`, `GetCategoryFileCount(slot, category)`, `CategoryExists(slot, category)`, `GetResolvingSlot(slot, category)` (which slot in the fallback chain actually supplies the audio — the slot itself, a fallback slot, or `""`).
- Config/debug: `GetAPIVersion()`, `ReloadConfig()`, `DebugPlayFile(path, Actor, flags, priority)`.
- Papyrus (non-native) wrappers: `WaitForHandle`, `PlayVoiceAndWait`, `PlaySFXAndWait`, `Play(category, Actor, waitForCompletion, ...)`.

**`AudioUtilPPA.psc`** (`Hidden`) — optional PPA bridge: `IsConnected()`, `SetEventRate(ms)`, `GetContext(akReceiver)` (bitmask), `GetDepth(Actor)`, `GetVaginalOpening(Actor)`, `GetAnalOpening(Actor)`. Consumers read the cached snapshot cheaply and/or handle mod events `AudioUtilPPA_Update` / `AudioUtilPPA_End`.

**`TomlUtil.psc`** (`Hidden`) — generic, audio-independent TOML reader/writer: `GetAPIVersion()`, `GetInt/GetFloat/GetString/GetBool(asFile, asKey, default)`, `GetStringArray(asFile, asKey)`, `HasKey`, `Reload(asFile)`, and (API v2) comment-preserving scalar writers `SetInt/SetFloat/SetString/SetBool(asFile, asKey, value)` (+ non-native `ConsoleSet*` string-arg wrappers for the `toml set*` console commands). File path is Data-relative; dotted keys (`voice.pcvolume`).

**`AudioUtilTest.psc`** (`Hidden`) — console harness. Skyrim has **no** `cgf` command (that's Fallout 4); the global test functions are exposed as real console commands via **ConsoleUtil Extended** (CUE) configs in `dist\SKSE\CustomConsole\*.yaml` (e.g. `autest T1`, `au reload`). Legacy IVDT-hardcoded probes: T1 basic play, T2F flags/priority sweep, T3 PlayVoice, T4 shuffle-bag, T5 SFX, T6 channel replacement, T7 group duck, T8 PPA status, TReload. Content-agnostic (arg-driven, work on any install): `play <path>`, `playlip <path>` (same, but drives the player's mouth — authored `.lip`/fuz lip when present, else envelope/pseudo), `voice <slot> <category>`, `voicepc <category>`, `sfx <name>`. Debug/calibration (natives registered on this script, not the public API): `lipcap start|stop` (record the dialogue speaker's facegen keyframe blocks + playing topic-info to CSV — the instrument that verified the `.lip` slot map), `lipfiles on|off|status` (toggle `.lip`-phoneme vs envelope lipsync at runtime), `pseudolip on|off|status` (toggle pseudo-phoneme synthesis for lines without lip data).

Native registration lives in `PapyrusAPI::RegisterFuncs`, split across `SCRIPT_NAME="AudioUtil"`, `PPA_SCRIPT_NAME="AudioUtilPPA"`, `TOML_SCRIPT_NAME="TomlUtil"`. `API_VERSION` is `5` (v2 added `GetSlotVariation`, v3 added `GetResolvingSlot`, v4 added `GetHandlePath`, v5 added captions); `TOML_API_VERSION` is `2` (v2 added the `Set*` writers).

## PPA Bridge (Accurate Penetration)

- `include/API/AccuratePenetrationAPI.h` is a **recreated** PPA v1 interface (from the public PPA SKSE docs), resolved **dynamically** — the code never links against `AccuratePenetration.dll`. Key types: `SceneContext` bit flags (Vaginal=1, Anal=2, Oral=4, Aggressive=8, FemDom=16, Loving=32, Dirty=64, Boobjob=128, Handjob=256, Footjob=512, Masturbation=1024), `InteractionPartner` (penetrationDepth …), `AnimationUpdateEvent`, `InterfaceV1`. Entrypoint `AccuratePenetration_GetAPI_V1`.
- `PPABridge::TryConnect()` (kDataLoaded, gated on `[ppa] enable`) does GetModuleHandleW → GetProcAddress → version/size check → RegisterAnimationUpdateListener. The listener runs on PPA's thread **every frame for every actor**; it copies a per-receiver snapshot (context, depth = max across selfInteraction + partners, opening values, ending flag) into a mutex-guarded map. It sends `AudioUtilPPA_End` on `ending` (then erases state), else `AudioUtilPPA_Update` at most once per `event_rate_ms` per receiver **or immediately when the context bitmask changes**. Events marshal to the game thread via `SKSE::GetTaskInterface()` → `ModCallbackEvent`.
- `docs/ppa-api-assumptions.md` records the PPA author's answers: opening values are magic unsigned numbers (0.0 = closed, no defined scale — calibrate empirically); context bits are scene **classification** (like SexLab tags), NOT live collision — for "physically inserted now" require a context bit **AND** `depth > 0`; `ending` is always sent (state-erase is safe); the per-frame firehose must stay in C++ to avoid Papyrus VM lock contention.

Design: the firehose stays in the DLL; Papyrus only sees throttled events (2 s default) and cheap polls. Fails closed when PPA is absent.

## Distribution Layout (`dist/`)

`dist/` maps directly onto a Skyrim `Data\` install:

```
dist/
  SKSE/Plugins/AudioUtil.dll                   ← built by xmake
  SKSE/Plugins/AudioUtil/AudioUtil.toml        ← hand-written neutral SFW base config (owns globals)
  SKSE/Plugins/AudioUtil/config.example/*.toml  ← hand-written additive-overlay template (NOT loaded; copy into config\)
  SKSE/Plugins/AudioUtil/config/*.toml          ← additive overlays shipped by consumer add-on mods (merged on top)
  Scripts/AudioUtil.pex  AudioUtilPPA.pex       ← compiled by Pyro
          AudioUtilTest.pex  TomlUtil.pex
  Scripts/Source/*.psc                         ← source copies mirrored by pyro.lua
```

`.gitignore` ignores all of `dist/**` **except** the tracked, hand-written `dist/SKSE/Plugins/AudioUtil/AudioUtil.toml` and `dist/SKSE/Plugins/AudioUtil/config.example/*.toml` — everything else (DLL from xmake, `.pex`/`.psc` from Pyro) is generated. Pyro zips the whole `dist/` tree into `Release\AudioUtil-<version>.zip`.

## Gotchas & Non-obvious Details

- **Master Papyrus sources live in `papyrus\Source\`.** `dist\Scripts\Source\` is a generated mirror — never edit it (pyro.lua overwrites it).
- **CommonLibSSE-NG is a submodule** — init it before building (see [Build](#build)).
- All key/name matching in config and API is **case- and space-insensitive** (`Config::Normalize`).
- **Loose-file constraint:** folder scans (slot roots, folder-string categories, sfx) can't see BSA-packed audio. To play from a BSA, use `PlayFile` or an explicit `[slot.categories]` file list (the engine's resource loader resolves those from BSAs). **Lipsync needs a loose PCM wav.**
- **Playable formats: wav, xwm, fuz.** Scans pick up all three (loose); `PlayFile`/file lists resolve all three from BSAs too. A `.fuz` plays via its `FuzCache`-decoded PCM wav; captions key off the `.fuz` path itself and **fuz lines lipsync** — with **real phoneme curves** when the fuz's embedded LIP block parses (any vanilla dialogue line!), else the amplitude envelope over the decoded PCM. A loose wav gets phoneme lipsync by shipping a **same-stem `.lip`** beside it (generate offline with the CK's `LipGenerator.exe` or FaceFXWrapper; batch tool: `tools/lipgen/make_lips.py` reads caption sidecars as the spoken text and can also pack wav+lip into `.fuz`; `tools/lipsim/lipsim.html` plays/simulates wav+lip+fuz in a browser — mouth animation, channel timeline, pseudo-synthesis tuning sliders). Raw `.xwm` files play but skip lipsync.
- `sound_flags` / `sound_priority` default `0x1A` / `128`. If audio is silent or not 3D-positioned, sweep values with `DebugPlayFile`.
- Logs go to the SKSE logs dir as `AudioUtil.log`.
- Hardcoded game paths appear in `AudioUtil.ppj`, `.vscode/tasks.json`, `scripts/pyro.lua`, and the README — override via env for other machines.
- The default TOML ships with **no** slots/SFX (SFW-neutral by design). A preset mod that needs custom globals ships its **own** base `AudioUtil.toml` (overwriting the neutral one via load order); pure add-ons ship additive `AudioUtil\config\*.toml` overlays. Globals (`[general]`/`[ppa]`/`[lipsync]`/`[captions]`/`[gag]` toggles) are **base-only** — overlays that set them are ignored+warned; additive data (slots, sfx, maps, gag keywords/items) unions across all files (see the `Config` row). Whole slots are last-wins by `id` in sorted filename order.
